# Working on the Mahmoud Kronbi portfolio

This repo is the portfolio site of Mahmoud Kronbi, a finishing contractor in Lagos (RAZANCO Nigeria Limited). It's built with Next.js (App Router), React, TypeScript and Tailwind v4, and Vercel deploys `main` to production.

## Where things live

| Path | What it holds |
| --- | --- |
| `src/app/(site)/` | Routes: home, `/work/[slug]` project pages, `/cv` |
| `src/app/sitemap.ts`, `robots.ts` | Sitemap and robots |
| `src/content/` | All copy as typed records: `site.ts` (home page and contact), `projects.ts` (one record per project), `cv.ts` (CV page, PDF and Word file), `types.ts` |
| `src/content/photos.json` | Width, height and blur placeholder for every photo, generated by `scripts/build-photos.mjs` |
| `src/components/` | The design system: `Inlay` (scooped marble-inlay frame), `Marked` (a phrase highlighted in the text-selection rosso), gallery, lightbox, compare slider |
| `src/components/sections/` | Page sections. The home page's own styles are in `home.module.css` |
| `public/images/<project>/` | Source photos (JPEG, up to 2000 px) |
| `public/img/` | Every size of every photo as WebP, generated before `dev` and `build` by `scripts/build-photos.mjs` and served through the custom loader in `src/lib/image-loader.ts`. Not committed. |
| `public/cv/` | The CV as PDF (`npm run cv:pdf`) |
| `cv/` | The CV as an editable Word file (`npm run cv:docx`), not linked from the site |
| `scripts/` | Photo manifest and CV generators |

`media/`, `mockups/` and `.media-work/` are local only and never committed. `.media-work/` holds the photo originals, the selection list, and the export script. Read `.media-work/CONFIDENTIAL.md` before adding or changing any photo or copy.

## Publication rules

- Clients stay anonymous unless the user says otherwise; write "Private, name withheld".
- Facts we haven't confirmed are written as `verify('note')` in `src/content/`. They show as `[VERIFY: …]` in development and are left out of production builds. Never hard-code a guess.
- Only photos listed in `.media-work/selection.tsv` go on the site. Never add photos straight from `media/`.
- He has no engineering degree, so never call him "Engr.". Keep his date of birth, home address and reference phone numbers off the site and the CV.
- The site speaks in his voice: "I finish", "talk to me", "my role". Alt text still names him, and the CV stays pronoun-free.

## Running and checking

- Dev server: `npx next dev -p 3100` (the `site` entry in `.claude/launch.json`).
- Production check: `npx next build && npx next start -p 3200`.
- Type check `npx tsc --noEmit`; lint the files you touched with `npx eslint <files>`.
- Photos are never resized on request: `scripts/build-photos.mjs` prepares every width in `next.config.ts` (`deviceSizes` + `imageSizes`) ahead of time. If you change those widths, change `WIDTHS` in the script too. After adding photos, run `npm run photos` (it also runs automatically before `dev` and `build`). After changing `src/content/cv.ts`, run `npm run cv:pdf` (needs `next start` on 3200) and `npm run cv:docx`.

## Shipping

Work on a branch, with commit messages like `feat: …`, `content: …`, `fix: …`, `chore: …`. Open a PR; the user merges, and Vercel deploys `main`. Don't install packages without asking.
